# 系统概况

登录后的首页。侧栏固定，顶栏和内容在剩余宽度里。

| 区域 | 尺寸 | 样式 |
| --- | --- | --- |
| 侧栏 | 宽 216，通高 | 白底；logo 区高约 59，内边距 16×12；选中项高 40、左右 16、圆角 12、底 `#1677ff`、字白 |
| 顶栏 | 高 56，左右 24 | 白底，阴影 `--shadow-header`；面包屑 14px |
| 页头 | 内边距 6×24×12 | 白底，圆角 16，同一套顶栏阴影 |
| 页底 | `#f5f5f5` | 指标卡白底、圆角 12 |
| 启用条 | 高 22 | 斜纹 `-45deg`，6px 一段；四色见 token |
| 正文 | 14 / rgba(0,0,0,.88) | 问候 22/700，区块标题 16/600 |
