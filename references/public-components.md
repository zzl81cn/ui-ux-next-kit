# 公共组件

新项目和审计都用这里的契约还原，不看实现源码自己补数字。来源是范本 `docs/UI_SPEC_EXTRACTION.md` 与 `docs/DESIGN.md` §3.1–§3.15，同步到 2026-11-26。数字、色值、文案和时长以本文件为准。对不上验收清单就改实现，不要改这里的数字。产品名在本套件里用「管理控制台」，Logo 和 favicon 用套件自带的默认图。

UI、UX 规范未尽事宜，严格按照 antd 的规范实现。本文件写了的尺寸、文案、顺序和状态仍以本文件为准。

颜色分两种，表里写了跟不跟主题：

- **跟主题：** 用 `colorPrimary` 以及 `--ant-color-link`、`--ant-color-error`。
- **固定：** 不要改成主题色。登录画布、部门树轨道、图表色板、概览胶囊都是固定色。

可复用的是「上面筛选 + 下面满高表」，以及看板的骨架和动效。API执行记录、数据统计只是填进去的例子：换产品时换列或换卡片，骨架不用重写。

## 筛选组件

来源：范本 `docs/DESIGN.md` §3.1。实现以 `apps/console/src/components/DashFilterPanel.tsx` 和 `styles.css` 里 `.dash-filter*` 为准。

页面上的筛选条用 `DashFilterPanel` + `DashFilterField`。不另写一排表单。颜色走 `ConfigProvider` / `--ant-*`，不单做一版筛选配色。控件高 34px、圆角 5px，见该文档 §3。

给桌面列表上查记录的人用。字段和「展开 / 重置 / 查询」在同一张网格里。窄容器能收起，展开时下面的表跟着让出高度。

### 布局

字段与按钮同一网格。列数按容器宽度（对位 Pro QueryFilter）。`columns` 可以锁死。

| 容器宽 | 列数（含操作区） |
| --- | --- |
| < 576 | 1 |
| 576–767 | 2 |
| 768–1599 | 3 |
| ≥ 1600 | 4 |

- 收起：首行露出 `列数 - 1` 个字段，至少 1 个。末列是按钮。字段数放得下就不显示「展开」。
- 展开：字段按行铺满，按钮落到最后一行末列。
- 按钮顺序：展开/收起（链接按钮）→ 重置 → 查询（主按钮）。查询可以处于 loading，字段仍留在原地。
- 顶栏「筛选条件」默认关（`showHead={false}`）。标签默认在控件上方。单字段需要左右排时用 `fieldLayout="horizontal"`。
- 内边距 13px 18px。列间距 24px，行间距 16px。

### 展开 / 收起

来源只这一处：范本 `docs/DESIGN.md` §3.1。高度、按钮位移、箭头旋转、新字段淡入都是 **0.48s**，缓动 `cubic-bezier(0.22, 1, 0.36, 1)`。系统开启「减少动效」时直接换成另一态，这些都不播。

先把容器钉在当前看见的像素高度，关掉过渡量出目标高度，再打开过渡滑过去。量高的那一下不能画出来。滑动时内容贴顶、溢出隐藏，首行留在原处。停稳后高度回到 `auto`、溢出可见，日期和下拉不被裁切。高度没变化时，最迟 **560ms** 也要收成这个稳态。

按钮和高度一起动。点下去之前记下按钮的屏幕位置；网格变了之后，按钮从旧位置平移到新格子，再用同一条 0.48s 滑到终点。滑动时按钮盖在字段上面。动画没播完又点一下，从当时的高度反向滑。上一次的结束回调作废。

收起：

1. 第一行以外的字段立刻拿掉，不淡出。
2. 文案马上改成「展开」。箭头先保持朝上。
3. 高度滑回首行，按钮滑回首行末列。
4. 高度停稳后，箭头再用 0.48s 转回朝下。

展开：文案马上改成「收起」，箭头和高度一起转 180°。高度滑开，新字段只做透明度从 0 到 1，自己不位移。按钮滑到最后一行末列。

### 验收

- [ ] 收起后只见首行字段和三个按钮，控件高 34px
- [ ] 收起时多余字段先消失，再看到容器变矮。首行不随底边移动，不与消失中的字段重叠
- [ ] 按钮和高度同一条 0.48s 曲线一起动。按钮从点下去时的位置滑到新格子，不先跳再滑
- [ ] 展开后按钮在最后一行右侧，新字段只淡入。表体高度跟着让位
- [ ] 动画中途再点，从当前高度反向滑
- [ ] 收起时箭头在高度停稳后才转回朝下。展开时箭头和高度一起转
- [ ] 减少动效时无高度动画
- [ ] 动画结束后选择器、日期面板能完整弹出

## 穿梭组件

来源：机器人管理 → 机器人组 →「管理机器人」。实现是 `apps/console/src/pages/workers/RobotGroupsTab.tsx` 里的 `ManageRobotsModal`，用 antd `Transfer`，左右列表用 `Table`。颜色不另做一套，走 `ConfigProvider` / `--ant-*`。中间挪动按钮用 Transfer 自带的操作区，不手写第二套箭头。

给要把条目从「全部」挪到「已选」的人用。左右都能搜、都能勾选。勾选后用中间按钮挪；表头全选再点按钮等于全部添加或全部移除。行可以拖到对侧。点行本身是勾选，不是立刻挪过去。

### 布局

弹层标题是「管理机器人 · 组名」。左右两栏加中间操作区。左栏标题「全部机器人」，右栏标题「已选：N个」。

| Token | 值 | 落点 |
| --- | --- | --- |
| 弹层宽 | `min(920px, 96vw)` | `Modal` |
| 弹层内容上内边距 | 12px | `Modal` `styles.body` |
| 单侧栏宽 | 380px | `Transfer` `styles.section.width` |
| 单侧栏高 | 420px | `Transfer` `styles.section.height` |
| 中间操作区左右内边距 | 8px | `Transfer` `styles.actions` |
| 表体可滚高度 | 280px | 内嵌 `Table` `scroll.y`。不是 300，见下面「高度账」 |
| 拖放承接区最小高 | 320px | 包住表格的那一层 |
| 表尺寸 | `small` | 内嵌 `Table` |
| 单位 | 个 | `locale.itemUnit` / `itemsUnit` |
| 底栏 | antd `Modal` 默认底栏 | 见下面「底栏」 |

**高度账**：栏高 420px，减去栏头 40px 和搜索框那一段 57px，列表区只剩约 323px。表头 39px，所以表体最多 284px，取 280px。表头 39 加表体 280，一共 319px，装进 320px 的承接区。表体写成 300 会让满表时整张表比栏多出十几 px，从栏的下沿溢出，盖住弹层底栏的按钮。数据少时看不出来，要放 8 个以上机器人才会暴露。

**底栏**：取消和确定放在弹层白色面板里，右对齐，取消在左、确定在右，间距 8px，底栏上沿离内容区 12px。底栏不许被任何内容盖住：栏、表、承接区都装在 420px 以内，超出的在表体里滚，不溢到栏外。通用规矩见「弹层通用规矩」。

搜索框占位「输入机器人账号」。左右都筛。匹配名称、账号、id、上报 IP，忽略大小写。

内嵌表三列：名称（省略溢出）、状态（宽 90）、上报 IP（宽 120）。空表左栏「没有可添加的机器人」，右栏「还没选机器人」。

状态只使用组件库标签色：离线默认标签，运行中 `blue`，空闲 `green`。不另写 hex。

`showSelectAll={false}`：不使用 Transfer 自带的列表头全选，全选走表格表头。

### 交互

- 确定才提交。取消或关掉不改成员。提交中确定按钮 loading。
- 关闭后销毁内容（`destroyOnHidden`），下次打开用当前组成员，不留上次勾选。
- 组成员在机器人列表里已经删掉的，右侧仍显示，名称退回 id，避免一保存就悄悄丢掉。
- 拖拽：从一侧拖到另一侧才生效，拖回原侧无效。若该行已在勾选里，拖走整组勾选；否则只拖这一行。光标 `grab`。
- 搜索进行中，搜索框留在原地，行也不换边。

### 验收

- [ ] 弹层在 920px 以内，窄屏不超过视口 96%
- [ ] 左右栏各 380×420，表体在 280px 高度内滚动
- [ ] 放 10 个以上机器人，左右两侧表都不超出栏的下沿。取消、确定留在白色面板右下角，没有被表盖住，也没有掉出弹层
- [ ] 勾选后只能经中间按钮或拖到对侧移动，单击行只改勾选
- [ ] 表头全选再点中间按钮，该侧当前行全部移到对侧
- [ ] 左右搜索都能按名称、账号、IP 过滤
- [ ] 左空、右空文案不同
- [ ] 取消后成员不变；确定后才保存
- [ ] 状态色只用标签的默认 / blue / green

## 弹层通用规矩

所有居中弹层。抽屉另见各页。只用 antd `Modal`，不手写遮罩和面板。

| 项 | 值 |
| --- | --- |
| 面板 | 白底（深色 `#1f1f1f`），圆角 8px，一整块。标题、内容、底栏都在这一块里 |
| 标题 | 面板顶部，16px、字重 600，右上角关闭叉 |
| 内容 | 标题下面，上内边距 12px |
| 底栏 | 内容下面 12px。按钮右对齐，取消在左、主操作在右，间距 8px。底栏在面板里 |
| 最大高 | 面板不超过视口高减 2 × 24px（用 `centered`）。内容高过它时，内容区自己滚（`styles.body` 设 `maxHeight` 加 `overflowY: auto`），标题和底栏不动 |
| 宽 | `min(目标宽, 96vw)`，不写死 px |
| 关闭 | 取消、右上叉、遮罩、Esc 都等于放弃，不改数据 |
| 提交中 | 主操作按钮 loading，取消仍可点 |
| 销毁 | 关闭后销毁内容（`destroyOnHidden`），下次打开重新取数 |

内容必须装在面板里。任何子块（表、栏、列表）比内容区高，就在子块里滚，不许溢出去盖住底栏。子块高度要做加法：栏头、搜索框、表头、表体加起来不超过容器的高；写固定高前先量，别凭整数估。底栏按钮不放进内容里，也不写绝对定位。

- [ ] 任何弹层都是一整块面板，标题、内容、底栏在同一块白底里
- [ ] 取消、确定在面板右下角，取消在左，间距 8px，没有被盖住，也没有跑到面板外
- [ ] 内容放满、放多时，底栏位置不变，内容区自己滚
- [ ] 窄屏、矮屏弹层不超过视口

## 部门树

来源：范本 `docs/DESIGN.md` §3.2，可测量尺寸来自 `docs/UI_SPEC_EXTRACTION.md` §3。路由 `#/settings/departments`。图形轨道对齐官网产品分类，但部门只有一个公司根。下面这些和产品分类不同，不能改回去。

- 概览胶囊保持黄绿 `#c8f55a` 和紫 `#7c5cff`，不跟控制台主色。
- 公司一直吸在顶上。二级部门吸在它下面一行，滚到下一个再换。产品分类是多个根轮流吸顶，不要搬回来。
- 面板高度按主内容区剩余空间算，扣掉底部内边距。不要用 `100dvh` 减去固定间隙，否则页面右侧多出滚动条。
- 公司可以改名，不能拖、不能换上级、不能删除。最后一个二级部门的圆点之下不再画公司那根竖线。

附属信息是「用户 / 兼职 / 应用 / 机器人 / 组」的计数，没有 slug。没有上架开关，没有层级筛选、状态筛选。搜索时整棵树禁止拖拽。根的拖拽位留空，宽度仍占 18px，避免子行轨道错位。

高度按主内容区可视底边现算，并听这个容器的 scroll、尺寸和窗口 resize，不能只在挂载时量一次。

### 一行

行高 48px，圆角 4px，单行不换行。从左到右：拖拽柄 18×48（不能拖的行用同宽空位）、轨道、展开钮 22×48、内容。

内容区内：名称 14px / 字重 500；附属信息 12px，过长省略，没有计数就不渲染；层级徽章 `L{depth}`，根是 L0；操作三个链接按钮（编辑、添加子部门、删除），高 32px。删除是 danger。

未悬停时三个操作都在，色为 `colorTextTertiary`（含删除）。悬停或焦点在按钮上：普通按钮 `colorLink`，删除 `colorError`。视口小于 768px 只留图标。

### 轨道

| Token | 值 |
| --- | --- |
| 缩进 | 20px |
| 节点圆直径 | 8px |
| 线宽 | 2px，圆头 |
| 线衔接重叠 | 1px |
| 圆点列中心 | `level * 20 + 10` |

浅色 8 色循环：`#1677ff #722ed1 #13c2c2 #faad14 #eb2f96 #52c41a #fa541c #2f54eb`。深色：`#4096ff #9254de #36cfc9 #ffc53d #f759ab #73d13d #ff7a45 #597ef7`。本层圆点和连线用 `palette[depth % 8]`。换主色后这 8 色不变。

有子节点且已展开：空心圆，填充是容器底色，描边是本层色。其余实心。

最后一个二级部门：圆点以下和它的子孙左侧不再画公司那根竖线。更早的二级部门，子孙左侧仍有这根干。

可见行斑马：奇数行底为 `colorFillQuaternary`。悬停改为 `colorFillTertiary`，过渡 0.12s。悬停层用行的 `::before`，不盖住文字。

### 吸顶

公司 `position: sticky; top: 0; z-index: 4`。二级部门 `top: 48px; z-index: 3`。吸顶行背景用不透明容器底色。已经吸住时阴影为 `0 1px 0` 分割线加 `0 2px 8px rgba(0,0,0,0.08)`。

### 拖拽

只允许同一父节点下改顺序。行前一半落在前面，后一半落在后面。不允许拖成子节点。换上级走编辑弹窗。根行不开始拖拽。搜索时去掉拖拽柄。

拖拽中的行不透明度 0.45。将落下的位置用 2px `colorPrimary` 指示线。不允许的目标不画线。

## 筛选列表

来源：范本 `docs/DESIGN.md` §3 的表高数字和 §4 的骨架。筛选条本身见上面的「筛选组件」（同文件 §3.1），这里不重复 34px 和展开收起。

这是桌面常规列表的组合方式：上面一条筛选，下面一张满高表。业务页只引这套，不在页面里再铺裸 `ProTable` 或 `<table>`。列、空态文案、行上的操作由具体页面另写，见下一节的 API执行记录。

### 骨架

```tsx
<ListPageShell>
  <Space className="console-list-stack" orientation="vertical" size="middle" style={{ width: "100%" }}>
    {/* 可选：Tabs / Alert */}
    <div className="console-executions-pane">
      <DashFilterPanel onReset={…} onSearch={…}>…</DashFilterPanel>
      <DataTable fullHeight search={false} scroll={{ x: "max-content" }} … />
    </div>
  </Space>
</ListPageShell>
```

筛选在表外，表的 `search` 关掉。两者同一纵列，间距 16px。只有表体滚动，整页不滚。

### 高度

| Token | 值 |
| --- | --- |
| 表卡底内边距 | 16px |
| 页底 | 主内容区下内边距 16px + 页容器下内边距 8px |
| 底边预留 | 24px。算表体高度时扣掉这一层，不要再加 |
| 分页与表体间距 | 8px |
| 分页占位 | 上边距 8px + 约 34px。加载中分页还没出来时，表下先留 42px |
| 表体最小高 | 230px。矮屏或筛选展开后仍能看约 5 行 |

表体高度按视口现算：视口高减去表头底边、分页和 24px 底边预留。不要用内容撑高的外壳反推。筛选展开、窗口变化都要重算。筛选变高只让表体变矮，分页仍靠近内容区底边，整页不出滚动条。

### 验收

- [ ] 筛选在表外，表内没有第二套查询区
- [ ] 整页不滚动。筛选展开后只是表体变矮
- [ ] 分页距表体 8px，下面约有 24px 预留，不贴浏览器底，也不空出一大截
- [ ] 加载中表体已经占住高度，分页出现时不把表顶跳

## API执行记录

来源：范本 `docs/UI_SPEC_EXTRACTION.md` §4。路由 `#/jobs?record=api`。筛选条用上一节，展开收起用「筛选组件」。本节只写填进这套骨架的列、空态和操作。换一页列表时，换掉这些，满高表不用重写。

给在「执行记录」里看每一次派单的人用。一行是一轮派单或续跑，不是一批任务。手机不用这张表。详情抽屉里的日志、进度、步骤不在本节，本节只规定点「详情」打开抽屉。

页顶三个页签：常规任务记录、高级任务记录、API执行记录（范本原名）。套件演示换成更宽泛的「全部执行 / 计划执行 / 手动执行」，并把填好的这一页放在第一个。侧栏「执行记录」不带参数时落在第一个页签，所以新项目先让人看到填好的那页。页签名按产品换，页签条的几何不变。API 页签内可以有一条下钻提示：「只看队列项 #N 的执行」，右侧「看全部」。

筛选卡紧贴在列表卡上面，间距 16px，七个字段，顺序是：应用名称（可清空、回车查询）、执行结果（运行中 / 成功 / 失败 / 已停止，可清空，空着表示全部）、执行机器人（名称或标识，可清空、回车查询、模糊）、触发时间、执行时间、结束时间（三个都是日期范围，和数据统计页同一个日历范围，可清空，控件高 34px）、MIS_ID（只留数字、可清空、回车查询）。三个时间的日历只选日期，不展示时分秒。查询时开始日按北京时间 00:00:00，结束日按 23:59:59，两端都包含，空着表示不限。还没开始的派单不进执行时间，还没结束的派单不进结束时间。提示：「按应用名称、执行结果、执行机器人、触发时间、执行时间、结束时间、MIS 任务号筛选派单记录。应用名称、执行机器人和 MIS 任务号可模糊。三个时间只选日期，开始日按 00:00:00、结束日按 23:59:59（北京时间）；不选则不限」。按钮仍是展开 → 重置 → 查询。容器是 3 列时收起只露前两个字段；到 4 列时收起露前三个，三个时间和 MIS_ID 在展开里。不要把字段塞进表卡标题那一行，也不要在列名上再挂一套漏斗；`search` 关掉，字段仍在那张卡里。套件演示不再自加字段，要多几个筛选也只加在这七个之后。

页签条、筛选卡、列表卡圆角 12，边和阴影与数据统计卡片相同。浅色边 `rgba(15, 23, 32, 0.06)`，深色边 `rgba(255, 255, 255, 0.08)`，阴影 `--console-elevation-1`。深色列表卡左上角有一层很淡的蓝光，和问候卡同一方向。

表题「API执行记录」（演示里写「执行记录」）。工具栏有密度、刷新和列设置，不要全屏。密度是公共表的默认，各页不要再关掉。选过的宽松、中等或紧凑记在这台浏览器，刷新不丢。所有公共表共用这一份，不按页各记一份，也不进服务端。没选过是中等。整表工具条关掉的页不单独补这颗按钮。菜单树表有密度和刷新，不要全屏和列设置，密度仍是这一份。

| 触发时间 | 192 | 日期时间，单行。宽松（左右内边距 16px）也不换行。可拖宽 |

执行结果用语义色标签，跟主题，不另配一套色：

筛选项只有运行中、成功、失败、已停止。待领取和停止中会出现在格子里，但筛选项里没有。

表内字色是 `colorText`（`rgba(0,0,0,0.88)`），表头与单元格相同。不要开整页抗锯齿，否则同色会变浅。第 2、4、6… 行底为 `colorFillAlter`。悬停整行（含固定列）用 `colorPrimaryBg`，过渡关掉。固定列的斑马底叠在不透明容器底色上。

固定列用表格自己的左固定、右固定，不要再画一层表头。有声明宽度的列锁在这个宽度上，表头和表体都用它，宽松密度下也不能被内容撑开。滚动条占位跟表体滚动条的实际宽度。表体有纵向滚动条时，表头留出同样的占位，「操作」表头的左缘和「详情」的左缘对齐。横向滚到内容被挡住时，左固定列右侧要有和右固定列同一套的边缘阴影。阴影画在格子外侧，省略只裁格子里的文字。

操作列是一个节点包住三个文字链，间距 16px，不换行。不要把三个链接当成数组交给表格，否则间距会变成 8px 再叠一层。

分页文案是「显示第 {起} 到第 {止} 条记录，共 {总} 条记录」，默认每页 20，可改每页条数。

## 用户管理

路由 `#/settings/users`。只做桌面，窄屏仍套壳。这一页只是「筛选 + 满高表」的一个填法，骨架照「筛选列表」，下面只写这一页自己的东西。

**页头与骨架。** 页题「用户管理」，副题「控制台账号；角色在此指定」。从上到下：副题、筛选卡、表。筛选卡在表外，表体吃满剩下的高度，奇偶行浅底，悬停整行变色。不分页，数据一次取回，筛选在前端做。

**筛选卡。** 五项，顺序固定：

| 项 | 控件 | 占位 | 规则 |
| --- | --- | --- | --- |
| 用户名 | 输入框，可清空 | 用户名 | 回车即查，包含匹配，不分大小写 |
| 显示名 | 输入框，可清空 | 显示名 | 同上 |
| 电子邮箱 | 输入框，可清空 | 电子邮箱 | 同上 |
| 角色 | 下拉，可清空 | 全部角色 | 选项是现有的角色，不写死 |
| 状态 | 下拉，可清空 | 全部状态 | 只有「启用」「禁用」两项 |

**六列。** 宽度写死，表体横向不够时出滚动条，不压缩列：

| 列 | 宽 | 内容 |
| --- | --- | --- |
| 用户名 | 140 | 文字 |
| 显示名 | 140 | 文字 |
| 电子邮箱 | 220 | 文字，没填写「—」 |

**状态列。** 开关点一下直接保存，不弹确认：成功提示「已启用」或「已禁用」，行里立刻变，已经开着的抽屉里「启用」同步。开关旁的标签只在需要时出现：

- 橙色「待改密」，悬停：有时限写「须在 {时间} 前登录并改密，否则锁定」，没有时限写「须登录并改密」。时间是本地 24 小时制。

**当前登录账号那一行。** 开关禁用，悬停「不能停用当前登录账号」。「删除」禁用，文字仍在、色是 `colorTextDisabled`，悬停「不能删除当前登录账号」。

**删除确认。** 点「删除」先弹确认：标题「删除用户」，正文「删除「显示名（用户名）」？删除后该账号无法再登录。」，按钮「删除」（危险色）和「取消」。成功提示「已删除」，表刷新。如果是在抽屉里删，就关掉抽屉再刷新。

**空表。** 有筛选条件时写「没有符合条件的用户。清空筛选或换条件再试。」；一个用户都没有时写「还没有控制台用户。点「新建用户」添加账号。」；加载失败写「加载失败」，能拿到原因就写原因。

**抽屉。** 新建、查看、编辑是同一只右侧抽屉，宽 480px，三种模式，标题分别是「新建用户」「用户详情」「编辑用户」。按钮在标题栏右侧，不在底栏（这点和菜单抽屉不同，不要照抄）：

| 模式 | 标题栏按钮 |
| --- | --- |
| 新建 | 「取消」「创建」 |
| 编辑 | 「取消」「保存」 |
| 查看 | 「关闭」「编辑」，点「编辑」在原抽屉里切成编辑，不再开第二只 |

关掉即销毁，再开是当前这一行，不带上一次的值和校验提示。关闭动画里标题和表单不闪空。

字段从上到下：

| 字段 | 出现 | 规则 |
| --- | --- | --- |
| 用户名 | 全部 | 只有新建能填，编辑和查看只读。必填，2–32 位，字母或数字开头，只含字母、数字、点、下划线、短横线。占位「字母或数字开头，2–32 位」。重名时在字段下写「用户名已存在」 |
| 电子邮箱 | 全部 | 必填，最长 254，要是邮箱格式。占位「name@example.com」 |
| 显示名 | 全部 | 必填，最长 64 |
| 角色 | 全部 | 必选，下拉，每项写「角色名 — 说明」。新建默认「查看者」 |
| 启用 | 编辑、查看 | 开关 |
| 初始密码 | 新建 | 必填。说明：临时密码，可设简单密码；用户须在「登录安全」设定的时限内（默认 8 小时）登录并改密，超时账号锁定，需管理员再次重置 |
| 重置密码（留空不改） | 编辑 | 可空。说明：可设简单密码；重置后用户须在时限内（默认 8 小时）登录并改密，超时账号锁定，需再次重置。填了就是重置，同时清掉「已锁定」 |
| 创建时间、更新时间 | 查看 | 只读，本地 24 小时制 |

密码规则：不能全是空格，最长 72 字节（一个汉字算多个字节），不受登录安全里「最短长度」的限制，因为这是临时密码，复杂度在用户首次改密时再校验。查看模式整张表单禁用，不校验。校验提示在字段下面，不用弹层。

保存：主按钮在保存中转圈。成功提示「用户已创建」或「已保存」，抽屉关掉，表刷新。失败提示「创建失败」或「保存失败」，后面带原因，抽屉不关，已填的内容不丢。

**不搬：**

- 查看和编辑不做成两只抽屉
- 不做批量删除、批量启停
- 不把「重置密码」拆成另一个按钮，它就是编辑里的一个字段
- 不给当前登录账号停用或删除的口子
- 不放开用户名的编辑

## 登录页

来源：范本 `docs/UI_SPEC_EXTRACTION.md` §5。`docs/DESIGN.md` §3.4 只记行为，尺寸以本节为准。路由 `#/login`。还原时按文末验收清单逐条自检，对不上就改实现，不要改这里的数字。

整页只有一张居中卡片，没有顶栏、侧栏、页脚。控件用 Ant Design 6 的表单、大号输入框和主按钮。卡片、画布、验证码底和默认 Logo 是写死的尺寸。不要覆盖 `.ant-input` 去改高度、圆角或聚焦环。

给已经有账号的人输密码。账号和密码经常被浏览器填好，所以打开后焦点在验证码，不在账号。

标志、标题和角标不在这一页单独配置，和进系统后的顶栏读同一份，见「品牌」。入口在系统配置的「品牌标识」。

没配时：左上是高 40px 的默认 Logo（一张图，套件自带），没有角标，标题「管理控制台」。副标题仍是「使用账号密码登录」。登录页不换深色图。

配了之后登录页只展示结果：导航 Logo 高 40px、宽按比例，图片 `alt` 留空；站点名称替换标题；角标非空才出现在标题右侧。浏览器标签用替代文字，没有则用站点名，再没有则用上面的缺省名。登录页始终用导航 Logo，不用深色 Logo。

### 解剖

视口内水平垂直居中。页边距 24px。卡片宽 `min(400px, 100%)`，窄屏只变窄，不换一套手机布局。

整页先画极光画布，卡片叠在上面。画布不跟主题主色，也不要换成照片。结构借鉴 uupm.cc 的 aurora（径向光 + 虚化漂浮光球），配色和点阵是自己的。自下而上五层，不重复平铺：

1. 底色线性渐变，180°。浅色 `#f8faff` → `#ebf1ff`；深色 `#0e1118` → `#131a2b`。
2. 青晕：椭圆 50% × 52%，中心水平 12%、垂直 92%，`rgb(0 191 159)`，浅色 16%、深色 16%，70% 处淡出。
3. 紫晕：椭圆 46% × 50%，中心水平 88%、垂直 58%，`rgb(168 85 247)`，浅色 16%、深色 18%，70% 处淡出。
4. 顶部蓝光：椭圆 90% × 70%，中心水平 50%、垂直 -18%（从上边缘外照进来），`rgb(22 93 255)`，浅色 24%、深色 34%，70% 处淡出。
5. 点阵：26px 间距、1px 圆点，浅色 `rgb(22 93 255 / 32%)`、深色 `rgb(147 180 255 / 28%)`。用椭圆 70% × 60%（中心水平 50%、垂直 38%）做渐隐遮罩，往边缘和下方消失，卡片周围可见，页角看不到。

另有两颗虚化光球（模糊 72px）叠在 1–5 层之上、卡片之下，各自缓慢来回漂移：

| 光球 | 位置 | 直径 | 颜色 | 漂移 |
| --- | --- | --- | --- | --- |
| A | 左 18%、上 14% | `clamp(220px, 28vw, 400px)` | 蓝 `rgb(22 93 255)`，浅 26%、深 30% | 14 秒，右下 48/36px，放大到 1.08，往返 |
| B | 右 16%、下 12% | `clamp(200px, 24vw, 340px)` | 紫 `rgb(222 104 255)`，浅 22%、深 18% | 17 秒，左上 44/32px，放大到 1.1，往返 |

系统要求减弱动效时光球停在起点。画布层 `pointer-events: none`，页面本身 `overflow: hidden`，光球漂出去不产生滚动条。

深浅由已保存的主题决定。这一页上没有主题开关。

卡片内从上到下：

1. 方标或 Logo。
2. 标题。有标签时标签跟在标题文字右侧，同一行，不换行。标题文字是彩色渐变字（借鉴 uupm.cc 的 gradient-text）：100° 渐变，浅色 `#165dff` → `#8b5cf6`(38%) → `#00b8a0`(68%) → `#165dff`，深色 `#5b8def` → `#b794f6` → `#2dd4bf` → `#5b8def`；`background-clip: text`，背景宽 220%，9 秒缓慢左右平移往返；减弱动效时停在起点。标签不跟着变色，仍按「尺寸」一节的表。
3. 副标题。
4. 账号。标签在上，大号输入框。
5. 密码。标签在上，大号密码框，右侧有眼睛，点击切换明文。
6. 验证码（服务端关掉验证码时，这一整行不出现，连标签一起去掉）。标签在上。下面是一条紧贴的组合：输入框在左、拉满剩余宽度，图片按钮在右，宽 112px，中间没有缝。图片由后端出图：白底，笔画按横向渐变上色（深蓝 `#1d4ed8` → 紫 `#7c3aed` → 青 `#0d9488` 循环取色，每张图的起始色随机；噪点和圆点跟着同色），不是黑白。字符本身、大小写不敏感、长度和过期规则不变。
7. 主按钮「登录」，与卡片内容同宽。
8. 「飞书登录」，紧挨在登录按钮下面。

登录卡片有一层**指针光晕**，对位产品官网商品卡的指针跟随光晕：指针在卡片上移动时，一团柔光跟着指针走，进卡片 0.3 秒淡入、出卡片 0.3 秒淡出。颜色用登录页的蓝紫：半径 340px 的圆，浅色 `rgb(22 93 255 / 13%)` → `rgb(139 92 246 / 7%)`(42%) → 透明；深色 `rgb(91 141 239 / 22%)` → `rgb(167 139 250 / 11%)` → 透明。光晕在卡片背景之上、内容之下，随卡片圆角裁切，不挡输入。指针位置用 `--mouse-x/--mouse-y`（相对卡片的像素）经 `requestAnimationFrame` 写入，不触发重渲染。**不搬**官网卡的悬停上浮与放大：登录表单在输入时跳动会干扰。无悬停设备（触屏）和系统要求减弱动效时不画。

表单不显示红色星号。空值文案在控件下方：「请输入账号」「请输入密码」「请输入验证码」。

### 顺序

1. 进入页面就向验证码接口要一张图。失败时顶部提示「验证码加载失败」。
2. 图到了之后清空验证码输入，并把焦点放进验证码框。
3. 点右侧图片再要一张，同样清空并重新聚焦。图片的替代文字是「验证码，点击刷新」。
4. 提交时「登录」按钮进入加载，字段留在原地。账号、密码在提交前按公钥加密，密码不明文出现在请求里。
5. 验证码开着但还没有验证码编号：提示「请刷新验证码」，并重新要图。
6. 成功且不需要改密：离开本页，去地址里的 `redirect`（必须以 `/` 开头），否则去 `#/stats`。
7. 成功但要改密：到期写「密码已到期，请先修改」，首次登录写「首次登录请先修改密码」。然后去账号设置。
8. 失败：顶部提示接口返回的原因，没有则「登录失败」。同时换一张验证码。
9. 本地还有未过期的登录态：不画这张卡片，直接去 `redirect` 或 `#/stats`。

验证码输入最多 6 个字符，关闭自动完成。账号的自动完成是 `username`，密码是 `current-password`。

### 不搬

- 不要加「忘记密码」、注册入口、页脚版权，也不要再加别的第三方登录。「飞书登录」是默认的第二颗按钮，不要拿掉。没配地址时点击提示「飞书登录暂未开通」，按钮留在原处。配了地址就整页跳过去。
- 不要把验证码画成独立一行，也不要在输入框和图片之间留间隙。
- 不要用主色重画默认 Logo。Logo 用套件里的蓝，主按钮才跟随 `colorPrimary`。
- 不要把画布改成纯色或照片。光晕、点阵和光球的位置、直径、透明度按「解剖」，不跟主题主色。光球不要加快漂移，登录页是静候页，不是动画页。
- 不要覆盖 `.ant-input` 去改高度、圆角或聚焦环。
- 不要在登录页再做一套品牌开关。登录页只展示「品牌」里的结果，深色主题下也不要改用深色 Logo。
- 加密、公钥和接口路径留在业务里。还原时只要做到：密码不明文提交，失败会换验证码，成功会离开本页。

## 品牌

来源：范本 `docs/UI_SPEC_EXTRACTION.md` §15。`docs/DESIGN.md` §3.12 只记行为，尺寸以本节为准。登录页的 Logo、标题、角标，和进系统后顶栏的 Logo、站点名、角标，是同一份配置。只改登录页，或只改顶栏，都不算做完。

宽 380px，窄屏最宽 `100vw - 24px`。从上到下：

**头。** 左右分开，垂直居中，内边距 `10px 8px 10px 16px`，下面一条 1px 分割线（`colorBorderSecondary`）。左：「消息通知」，字重 600，正文色；有未读时后面接「（N 条未读）」，没有未读就只有「消息通知」。右：两个小号链接按钮，「全部已读」「清空」。「全部已读」在没有未读时禁用。「清空」点了先弹确认「清空全部消息？」，按钮「清空」「取消」；列表为空时禁用。

**身子。** 三种状态：

- 加载中：骨架 3 行，无标题，内边距 `12px 16px`。
- 没有消息：简单空态图加「暂无消息」，上下内边距 28px。
- 有消息：列表，最大高 440px，超出自己滚，上下内边距 4px。

**一条消息**是整行可点的按钮，满宽，内边距 `10px 16px`，左右排，间距 10px，左对齐，悬停底 `colorFillTertiary`。

| 块 | 规格 |
| --- | --- |
| 未读点 | 左侧 6px 圆点，上边距 8px。未读是主色，已读是透明（仍占 6px，不让文字左右跳） |
| 标题行 | 13px，行高 1.5，可换行。**已读**是次要色、常规字重；**未读**是正文色、字重 600。行首是类型标签（见下），标签与标题间距 6px |

| 时间 | 12px，三级色。不足 1 分钟「刚刚」，不足 1 小时「N 分钟前」，不足 24 小时「N 小时前」，再久写「MM-DD HH:mm」 |

| 类型键 | 颜色 | 文案 |
| --- | --- | --- |
| `job.succeeded` | green | 跑完 |
| `job.failed` | red | 失败 |

| `app.owner_in`、`app.owner_out` | blue | 归属 |

**点一条**：未读的先标已读。有链接就关掉面板再跳过去，没有链接面板留着。**列表底部**还有更多时，居中一个「加载更多」链接，上下内边距 `4px 0 8px`，加载中显示 loading。每页 20 条，打开时现拉，不用旧缓存。

## 机器人头像

来源：范本 `docs/UI_SPEC_EXTRACTION.md` §16。`docs/DESIGN.md` §3.13 只记行为，尺寸以本节为准。当前任务、分组表，以及有执行机的产品的顶栏，用同一套圆标。直出后台的顶栏停在通知、主题、用户，不放这组圆。当前任务标题下的那一组仍要做。

圆里是字，不是照片。字号固定 18px，圆把超出的笔画裁掉。在线底色按机器人 id 做 `h = h × 31 + 码点` 再对 8 取余，同一台每次相同，不跟主题主色：

`#3b82f6`、`#4f5bd5`、`#7c5cf0`、`#a254d4`、`#13a8a8`、`#0e9ac7`、`#2f7d9e`、`#5b6b8c`。

中文名去掉括号和空格后，三个字以内全放，更长只放前两个。没有汉字时，取 `@` 前面的前两个字母并大写。字是白的。离线不用这组色，改用不透明灰：浅色底 `#c5cad3`、字 `#667085`；深色底 `#4a5160`、字 `#98a2b3`。

| 位置 | 直径 | 叠放 | 状态点 | 进场 | 悬停 |
| --- | --- | --- | --- | --- | --- |
| 顶栏桌面 | 24px | 每颗左边压住前一颗 6px，外加 2px 容器底色边。桌面最多 5 颗 | 9px，边 1.5px 容器底色，向右、向下各伸出 1px | 不做 | 圆上移 2px，盖住相邻的圆。过渡 0.1s |
| 顶栏手机 | 22px | 同上。左右内边距 4px，最多 3 颗 | 同上 | 不做 | 同上 |
| 当前任务 | 28px | 标题下第二行。从第二颗起叠进 8px，圆上 1px 容器色边。没有顶栏那圈色环。最多 3 颗，含离线 | 同上 | 前面的颗 0.72s 线性，错开 0.16s。0% 左移 22px、缩放 0.64；28% 左移 4px、缩放 0.94；39% 右移 5px、缩放 1.08；61% 再右移 5px。最后一颗（含 `+N`）0.44s，没有这次空顶 | 进场结束后才放大 1.12，盖到最上面。过渡 0.1s |
| 分组表 | 28px | 同样叠进 8px，1px 容器色边。默认最多 6 颗 | 不带 | 不做 | 放大 1.12，盖到最上面 |

顶栏只放在线的。运行中排在空闲前面，同一状态按中文名排序。条在顶栏里垂直居中，桌面左右内边距 8px。在线空闲再加 1.5px 成功色 70% 的环，运行中改成 1.5px 主色 80% 的环。无障碍名：有人在跑时「在线 N · 运行中 N」，否则「在线 N」。空闲点是成功色。运行中的点是主色，外面再加一圈 2px、主色 28%。离线点是四级文字色。当前任务的排序是运行中、在线空闲、离线。

超出颗数收成一颗 `+N`，字号 11、字重 600，底和字用离线灰。悬停弹出剩余名单：每行是圆、名称（超出省略）、状态标签，行距 8px。名单最窄 200px、最宽 280px，下面仍是那条链接。叠放组里的 `+N` 等 80ms 才开、120ms 才关。顶栏条上的 `+N` 没有这两段延迟。

悬停或键盘聚焦一颗圆，从下方弹出卡片，箭头指向圆的中心。进入延迟 80ms，离开延迟 120ms。卡片内边距 0、宽 280px。上部内边距 `12px 14px`，间距 12px：左边 48px 方头像（仍用身份色和同样的字），右边名称 14px、字重 600，下面 4px 是 12px 次要色说明。说明按有无拼接，中间用「 · 」：`登录名 …`、`IP …`、`操作员 …`、备注。都没有时写「暂无更多信息」。底部内边距 `8px 14px`，上边框，底是四级填充色，左右分开：状态标签和一条链接。离线标签是默认色「离线」。运行中是蓝色「运行中」。空闲是绿色「空闲」。顶栏和当前任务的链接文案是「执行机」，分组表是「管理组员」。点链接去对应页，不把整颗圆做成链接。聚焦环是 2px 主色、向外 2px。

顶栏每 15 秒拉一次在线机器人，窗口重新聚焦也拉，失败再试 1 次。还没有列表时，不要放转圈，也不要把顶栏撑高：先显示一颗空的机器人图标，尺寸与该处圆相同，底是次要填充色，图标是三级文字色。悬停提示「无在线机器人」。点这颗图标去执行机页。请求失败且仍然没有列表时，同一颗图标，提示改成「机器人状态加载失败」。已经显示出圆之后再刷新，圆先留着。当前任务还没有机器人时，圆的位置写次要色「无机器人」，不做牛顿摆。分组表一个组里没有机器人时写「—」。

减少动效时不撞入，悬停放大和顶栏上移仍保留。

## 看板

来源：范本 `docs/UI_SPEC_EXTRACTION.md` §6.2、§6.3、§6.5、§6.11。`docs/DESIGN.md` §3.5 只记行为，尺寸以本节为准。下面三栏的表是还原这一页的必做清单，不是草图。一块都不能少，也不要另画一种成功率条。跑批句子见「数据统计」，那是这一页的文案，不是可以删块的理由。

问候卡在上，下面是栏，栏间距 16px。整页滚动，卡片高度跟内容走，不拉成一样高，也不改成满高表。

内容区四边只有壳上的 16px。问候卡上面只有面包屑（最小高 22px，下边距 12px）。没有面包屑时不要留出同样的空带。侧栏和看板之间、看板和视口右缘之间，不要再加第二层留白，也不要给看板设 `max-width` 再居中。

栏数按内容区宽度切，不要按视口一到 768px 就三等分。侧栏 220px 还在时，视口过了 768，内容区仍然窄。

| 内容区宽 | 栏数 |
| --- | --- |
| < 640px | 1 列，「当前任务」在最上面，后面三栏上下叠 |
| 640–1039px | 2 列等宽。「当前任务」横跨两列放在最上面，下面**左列叠左栏、中栏，右列是右栏**，不用 CSS 多列自动平衡。右栏不整段落到左列下面 |
| ≥ 1040px | 3 列等分。**「当前任务」占左、中两列（宽 = 2 列 + 1 个栏间距），放在最上面。左栏其余卡片、中栏接在它下面，右栏从页顶一直通到底** |

对照视口（侧栏 220px、左右内边距各 16px）：大约 < 900px 为一列，900–1299px 为两列，≥ 1300px 为三列。内容区比这个更窄时（例如又多了一层留白），以内容区宽度为准，提前降列。

两列时左列叠左栏、中栏，右列是右栏，用显式网格分栏（执行时间轴第 2 行整行，左栏第 3 行第 1 列，中栏第 4 行第 1 列，右栏第 3–4 行第 2 列）。实测三栏高约 1060 / 800 / 1640，左 + 中 ≈ 右，两列大致等高。不要用 CSS 多列（`column-count` + `column-fill: balance`）让卡片自己往下流：右栏的「工作台」切页签（我的活动 / 操作审计 / 快捷入口 / 待办）高度会在约 350–990 之间变，多列会整页重新平衡，卡片被挪到别的位置甚至滚出视口，看着像「工作台没了」。显式分栏后「工作台」在右列最上面，页签怎么切它都不动，只有它下面的卡片跟着挪。正在运行不出现时，中栏少一张，后面的卡片自然上移，不留空位。一列仍是三栏上下叠。

「当前任务」不属于任何一栏，它是网格里单独的一块。三列时右栏从问候卡下面第一行就开始，和「当前任务」顶对齐。两列时用整行宽。一列时与其他卡片同宽。不要把它塞回左栏的一列里，也不要在一列宽里靠缩字号、让标签换行来硬放。原因是它里面有 18px 的分段进度条、右边的百分比胶囊、下面两行计数标签和一行「正在…」，单列（约 340–470px）放不下，标签会挤换行，卡头的标题块和操作区也会互相挤压。实测：视口 1700 时单栏 472px、「当前任务」960px；视口 1300 时单栏 339px、「当前任务」693px；两列（视口 1100）时「当前任务」848px，等于整个看板宽度。

### 图表与划过

运行趋势和用时占比必须是 ECharts。不要用另一套柱图或饼图库重画。提示挂到 `body`，避免被卡片裁掉。浅色提示底白、字 `#111827`；深色底 `#1f1f1f`、字 `#e6e8eb`。边框宽 0，字号 12。

运行趋势：横轴是窗口里的每一天，日期长于 10 个字符时只显示月-日。纵轴虚线网格。柱子堆叠，自下而上：未出结论（灰 `#8b919a` 的 38%）、失败（粉 `#ec4899`）、成功（绿 `#22c55e` 加白斜纹）。每天只有最上面那段顶角圆 5px。超过 14 天时柱最宽 14px，否则 22px。图例在右上，圆点 8px，顺序是失败、成功、未出结论。图旁有一句视觉上隐藏的摘要：「近 N 天：成功 x、失败 y、未出结论 z」。划过某一天：轴指示是一块阴影，提示列出这一天三层的次数。被划过的那一层保持，其余层让开（`emphasis.focus = series`）。没有扇区外扩。入场和每日操作量是同一套，每天一根柱子依次弹出：从左到右，单根 1000ms，`elasticOut`，第 i 天延迟 `i × 20ms`。延迟只按第几天算，同一天的三层（未出结论、失败、成功）同时长出，不是一层一层先后出。换窗口或数据更新再播一遍，参数相同（`animationDurationUpdate: 1000`、`animationEasingUpdate: elasticOut`、`animationDelayUpdate = i × 20ms`）。起点仍等「图表进场延迟」（数据到了之后，默认 100ms），不是数据一到就开播。首次 `resize()` 不能把动画打断，只在宽度真的变了才 resize。减少动效时整套不播，直接是最终状态。

用时占比：环的内半径 66%、外半径 86%，从 12 点起逆时针。扇区间隙 5°，圆角 6px，最小角度 3°。中心两行：总用时数字 14px 字重 600，下面「总用时」12px。最多 5 段按色板的分类色，其余并成灰色「其他」。图例圆点 8px。名称和百分比 14px、行高 22px。名称放不下时省略，悬停用组件库提示框显示全名，没被截断时不出现。百分比靠右，并留在卡片 20px 内边距里面。划过扇区或对应图例：提示是名称，下一行「时长 · 百分比」（百分比取整）。该扇区向外扩 8px，阴影模糊 12px、向下 2px、颜色 `rgba(0, 0, 0, 0.16)`。外扩和收回走 `stateAnimation`：300ms，`cubicOut`。入场是沿环转开：所有扇区从 12 点出发，按逆时针依次扫开，转满一圈，不是从圆心放大，也不是整环淡入。ECharts 用 `animationType: "expansion"`，1000ms，`cubicInOut`，中心总用时文字不参与动画。只播一次；切窗口、数据更新时用 `animationTypeUpdate: "transition"` 平滑变过去，不重新转一圈。`ResizeObserver` 首次回调不要 `resize()`，会打断入场。中心总用时和提示里的时长同一写法：不足 1 分钟「N 秒」，不足 1 小时「N.N 分钟」，否则「N.N 小时」。划过图例会同步高亮对应扇区并出同样的提示，离开收回。入场结束后动画总开关仍保持开着。总开关关掉时，这 300ms 不会发生，扇区会一下子弹出。减少动效时不展开，外扩的时长也是 0，8px 仍在。没有数据时：「窗口内没有已结束的运行」。

### 动效

数字和条第一次一起长出。数据到了之后再等「界面动效」里的毫秒数（默认 100）。减少动效，或这次进入页面已经播过，就立刻到位。「播过一次」按每次进入页面算（刷新、离开再回来都会再播一遍），不要记进 `sessionStorage` 或 `localStorage`；只有在页面里切 7 / 30 天、换日期、换主题不重播进场。

| 动作 | 值 |
| --- | --- |
| 板块上浮 | 520ms，`cubic-bezier(0.16, 1, 0.3, 1)`，从下 28px、缩放 0.985 到原位。错峰 100ms |
| 条目上浮 | 440ms，同一缓动，从下 16px、缩放 0.97。错峰 55ms |
| 条从 0 长出 | 见下面「一次成功率进场时序」 |
| 条悬停 | 放大 1.02、其余透明度 0.42、斜纹提到白 50%、底混入该色 8% 且轨道带该色阴影。四件同时发生。条长不变。不要把 1.02 加大 |
| 减少动效 | 进场、长条、悬停缩放都停掉 |

**一次成功率进场时序。** 数字和色条是两条各走各的时间线：

- 起点：数据到了先画空轨道（色条宽 0，徽章被轨道裁住看不见，数字停在 0），等「图表进场延迟」（默认 100ms，和用时占比环、运行趋势共用）后一起开跑。
- 色条：宽度从 0 过渡到目标宽，600ms，`cubic-bezier(0.16, 1, 0.3, 1)`，第 i 条延迟 `i × 55ms`。是 CSS 宽度过渡，不是关键帧。轨道里的色条不要带左右内边距，否则宽 0 时还剩一截。
- 徽章数字：从 0 跳到目标整数，700ms，缓动 `1 - (1 - t)⁴`（前快后收），`requestAnimationFrame` 逐帧写。所有条同时起跳，不按序号错开，和第 0 条色条同一刻开始。靠后的条数字已在跳、色条才刚开始长，这是对的，不要为了整齐把数字也错开。
- 0% 的条：色条从 0 长到 36px，数字停在 0。没有比率的条宽度保持 0、不放徽章。
- 切 7 天 / 30 天：色条不回 0，从当前宽度过渡到新宽度（600ms、同一缓动，延迟按重新排序后的序号），数字重新从 0 跳到新值（700ms）。颜色按排序后的位置取，顺序变了颜色跟着位置变。
- 减少动效：宽度和数字都直接到位。

比率以范本指标文档为准。没有比率时不放徽章，不写「没测」。整张卡一条都没有时写「这段窗口没有已结束的首次运行」。说明文字浅色 `rgba(0, 0, 0, 0.65)`，深色白 65%。

**页顶 API 提示条。** 控制面连不上时，问候卡上面出一条错误提示条（antd `Alert type="error" showIcon`），下边距 16px，标题「控制面 API 未连接」，说明一句请求地址和怎么起后端。连上了或还在加载时不出现。

**执行时间轴（ECharts `custom` 系列，对位 Apple 健康的睡眠阶段图）。** 卡片放在「当前任务」正下方，同样占左、中两列（两列时整行、一列时同宽）。卡头标题「执行时间轴」，右侧小号分段切换「24 小时 / 7 天」，默认 24 小时。图例一行：成功（绿）、失败（粉）、运行中（橙）、取消（灰），右端次要色 12px 说明「每段是一次派单，从执行机领走到结束」。图本体：横轴是时间（右端 = 现在），整点用虚线网格，标签 `HH:mm`（7 天窗口是 `M/D HH:mm`）；纵轴一条泳道一个**应用**，泳道高 54px，泳道线是实线，泳道名 11px 三级色贴在泳道左上角，不占坐标轴宽度。每次派单是泳道中线上的一个圆角色块：高约泳道的 46%（上限 30px），圆角 `min(8, 高/2, 宽/2)`，宽度按起止时间算、最窄 6px；块外一圈 3px 同色 22% 透明的光晕。时间上相邻（按开始时间排序）、间隔不超过 40 分钟、且不在同一条泳道的两段之间，画一条上下渐变的过渡带（宽 8–14px，上端取上面那块的色、下端取下面那块的色，32% 透明，画在色块下面），模拟睡眠阶段图里阶段切换的连贯感。悬停色块出提示：应用名、状态与 MIS、起止与时长、执行机。泳道按窗口内派单数从多到少，最多 8 条，超出的在图下方注明，不悄悄丢掉。只画已被执行机领走的派单，排队中的不画（还没占机器）；运行中的色块右端截到现在。没有数据时 `Empty` 写「近 24 小时没有被执行机领走的派单」。

**执行时间轴的进场：逐段出现。** 与其他图表共用同一个起步时刻（见「看板」的「动效」：数据到了之后等图表进场延迟，默认 100ms），然后按开始时间从左到右，一段接一段：每个色块（连同光晕）从自己的左边沿向右长出来并淡入，单段 600ms 缓出；相邻两段的起点间隔 `min(70ms, 1000ms / 段数)`，段再多总时长也不超过约 1 秒。过渡带跟着它连向的那一段出来，比色块晚 120ms。切「24 小时 / 7 天」时重画并重播；系统要求减弱动效时不播，直接出图。数据是窗口内被执行机领走的派单（窗口 24 或 168 小时），接口留在业务里。窗口内同一台机器的派单通常首尾相接，所以过渡带多；多台执行机并行时同一泳道的色块会重叠，这是已知局限，需要时再按执行机拆泳道。

**当前任务的进度条（分段堆叠条，不是单色进度条）。** 轨道代表这一批的总数，**有颜色的那一截 = 已处理（完成 + 失败 + 跳过），长度就是右边百分比**，里面按类型分段，一眼看出已处理的各类占比。未结（排队）不画颜色，留空轨道。不是 antd `Progress`，也不是整条铺满的构成图。结构从左到右：轨道（左边是带分段的已处理段，右边是空轨道）、右边 10px 一颗百分比胶囊。

**读法硬规矩：条长必须和胶囊百分比对得上。** 不要把「未结」画成一大段蓝色斜纹铺满轨道：它占了大头又亮又会动，读的人会当成进度填充，然后和胶囊上的 12% 对不上。实例：白名单 182 户，完成 5、跳过 17、未结 160，胶囊写 12%，则有颜色的只有轨道左边约 12%（绿 5 + 灰 17），其余 88% 是浅灰空轨道。

| 项 | 值 |
| --- | --- |
| 轨道 | 高 **18px**，全圆角，`overflow: hidden`，底 `rgba(127, 127, 127, 0.14)`，横向弹性撑满 |
| 分段 | 从左到右固定顺序：**完成**、**失败**、**跳过**，然后（只在执行机真在跑时）**运行中**。每段宽 = 该段数 ÷ 总数 × 轨道宽。数是 0 的段不画。每段最窄 2px，运行中段最窄 8px（户数再少也要看得见）。**未结的排队部分不画段**，是轨道底色（浅灰），不是蓝色。有颜色的总长 = 已处理段 + 运行中段 |
| 段色 | 完成 `#73d13d`（绿）、失败 `#ff4d4f`（红）、跳过 `#bfbfbf`（灰）、运行中 `#69b1ff`（浅蓝）。这四色是浅色下进度条自己的，不跟看板色板混。**深色下改用看板色板**（与旁边用时占比环同一组色）：完成 `#22c55e`、失败 `#ec4899`（与运行趋势「失败」同粉）、跳过 `#8b919a`、运行中 `#3b82f6`；斜纹从 18% / 22% 降到 10% / 13%，空轨道底 `rgba(255,255,255,0.07)`——浅色那组亮绿正红压在 `#141414` 上又亮又跳，和环、趋势图不是一家人。排队的空轨道是轨道底色，没有蓝 |
| 圆角 | 只有第一段左端、最后一段右端是全圆角，中间段是直角；只有一段时两端都圆 |
| 斜纹 | 已处理的每段都盖静态斜纹：`-45deg`，白 18% 的 7px 条、隔 7px（深色 10%）。和一次成功率的斜纹同一做法，只是更淡更宽。空轨道没有斜纹 |
| 斜纹流动 | **执行机真在跑时，整段有颜色的已处理部分一起向右流动**：盖在外层上的一层斜纹，各段交界处纹路连续，单元 20px，0.9s 线性无限循环，白 22%（深色 13%）。空轨道（排队）不动。空闲的未完成批次、已停的批次整条不动，免得看着像还在跑。减少动效时不动。原因：运行中通常只有 1 户，占 0.5% 宽，只让它那一小段动，看不出在流动 |
| 总数 | 总数是批次总户数。没给总数时取（完成 + 失败 + 跳过 + 排队 + 在跑）。分段宽按这个算，不是按「已处理」算 |
| 百分比胶囊 | 在轨道右边，高 18px，内边距 `0 8px`，全圆角，11px、字重 650、等宽数字。底是容器色，边 1px 主色 35%，字是主色。内容是**已结（完成 + 失败 + 跳过）占总数的百分比**，取整，写成「77%」。**胶囊在轨道外面**，不在色条里面，这点和一次成功率的徽章相反。悬停提示：「已处理 22 / 182（完成 5，跳过 17）」，为 0 的类别不写 |
| 悬停分段 | 每段一个提示：「已完成（含无权限等终态） N」「失败 / 待人工 N」「跳过 / 过期（未交付） N」「运行中 N」；悬停空轨道：「未结 N（排队 N，运行中 N）」 |
| 无障碍 | 整条 `role="img"`，名称「进度 77%：完成 N，失败 N，跳过 N，未结 N，共 N」 |

进场：还没有数据时只画空轨道，胶囊写 0%。数据第一次到了（延迟约 60ms）分段容器的宽度从 0 长到**已处理占比**（不是 100%），600ms，`cubic-bezier(0.16, 1, 0.3, 1)`，生长过程中各段比例不变。胶囊数字同时从 0 跳到目标，700ms，前快后收，**只跳这一次**。之后执行机上报的新进度：各段宽度用 0.35s 缓动平滑变过去，胶囊直接显示新数，不再从 0 重跳，条也不回 0。减少动效时直接到位。

条下面是计数标签，和进度条纵向间距 8px，标签间距 8px，可换行。按有没有「白名单」数据分两种，**不是把所有标签摆在一起**：

- 有白名单数据：「白名单 N 户」（灰）、「待跑 N」（蓝）、「有数据 N」（绿）、「无数据 N」（灰，为 0 不画）、「无权限 N」（灰，为 0 不画），最后一段次要色「已落字 x/N」。有失败或有未结时，下面再补一行 12px 次要色说明：「调度行另计：完成 N · 历史失败行 N（含旧抽表失败，不等于待跑） · 队列未结 N。无权限 / 待跑以白名单「税费种认定」列为准。」（后两段没有就不写）
- 没有白名单数据：「白名单 N 户」（灰，N 取总数）、「完成 N」（绿）、「失败待重跑 N」（红，为 0 不画）、「调度跳过 N」（灰，为 0 不画）、「队列未结 N」（蓝，为 0 不画）。
- 白名单列读失败：下面一行 12px 红字「白名单列读失败：原因」。

没有「总数」「成功」「跳过」这几个标签，总数只体现在「白名单 N 户」里。

另外：派单报错时在正文里用红字写错误原因；有自动续跑排期时多一行「自动续跑」金色标签加「上一轮有户在冷却 / 日切，计划 MM-DD HH:mm 自动开始」和主按钮「立即开始」。

**正在运行。** 只有执行记录里有在跑的才出现，没有就整张卡不占位。卡片小号，标题「正在运行」，里面一条链接：「N 条执行记录在跑」，有最久的一条时后面接「 · 最久已跑 X」，链接去执行记录里筛运行中的那页。

**健康小卡补充。** 三张小卡纵向叠，间距 12px。标题 12px，色 45% 黑（深色 45% 白），下边距 4px。数字跳动，字符串（「3 / 4」）原样显示，没有数据时数字位置写「—」。

## 控制台壳

来源：范本 `docs/UI_SPEC_EXTRACTION.md` §7。`docs/DESIGN.md` §3.6 只记行为，尺寸以本节为准。登录页以外的桌面页都坐在这只壳里。窄于 768px 时整只换成「手机壳」，不在这只壳上把侧栏挤扁。

### 解剖

布局是上顶栏、左侧栏，侧栏宽 **220px**，顶栏和侧栏都固定。没有页脚。深色下画布是纯黑，不要上深下浅的渐变。

顶栏左侧：高 28px 的 Logo，间距 8px，然后是站点名（默认「管理控制台」）。有站点标签时跟在站名后，颜色循环用登录页那张表。没有上传 Logo 时用套件自带的默认 Logo，深色主题有深色版就用深色版。上传了 Logo 时图片高 28px、宽按比例；深色主题优先用深色 Logo，加载失败再退回浅色那张。

直出后台的顶栏右侧从左到右：通知、主题、当前用户。通知是一颗铃铛，**点开要弹出消息通知面板**，规格见「消息通知」，只画图标和红点算没做。有执行机的产品才在通知左边加「机器人头像」的顶栏条。深浅色是通知和用户之间的一颗单独图标，不放进用户芯片。点它（不是悬停）从按钮右下拉出菜单，选完立刻换肤。悬停提示「主题设置」。无障碍名是「主题：」加上当前项的名字。

按钮宽 40px、高等于顶栏、圆角 0、图标 16px。浅色悬停底 `rgba(0,0,0,0.04)`，深色 `rgba(255,255,255,0.08)`。按钮图标跟着当前项：浅色是太阳，深色是月亮，跟随系统是调色盘。菜单三项都带图标，当前项右侧打勾：浅色是太阳，深色是月亮，跟随系统是显示器。默认「跟随系统」。选择写入本地，刷新后仍是这一项。浅色和深色立刻把 `html` 标成 `data-console-theme="light"` 或 `"dark"`。跟随系统时听 `prefers-color-scheme`。登录页没有这颗按钮，但用同一份已保存的选择。

当前用户是顶栏最右侧的一颗芯片，和主题图标分开。点它（不是悬停）从芯片右下拉出菜单。深浅色不进这个菜单。芯片高 40px，内边距 `0 12px 0 6px`，内部间距 8px，圆角 10，边框 1px 次要色，底 `colorFillQuaternary`。悬停底改成 `colorFillTertiary`，背景过渡 0.2s。头像 28px 圆，底 `#1f2329`，白色人像。名称字重 600，优先显示名，没有则登录名。有角色才出现实心主色标签、白字。箭头 12px，三级文字色，朝下。菜单第一项不可点：有登录名时是「显示名（登录名）」；然后齿轮「个人设置」、锁「修改密码」；分隔线；「退出登录」，退出后替换到 `#/login`。

浅色侧栏底白。菜单字色 `rgba(0,0,0,0.75)`。菜单项高 40px，图标和文字间距 8px。子菜单比顶层再缩进一档，左内边距 40px，折叠箭头对齐在右缘 16px。选中项两边都是白字、主色底 `#3b82f6`、投影 `0 6px 16px` 主色 42%。不再用 `#dbeafe`，深色也不用白 4%。不加指示条。当前页在某个分组里时：分组展开，标题是主色字、主色 18% 的底，子项仍是实心主色；分组收起，标题接过实心主色。外链新开窗口。顶栏右侧的通知、主题和用户芯片在同一条垂直中线上。用户芯片自己有悬停底，外面不再套一层。

内容区四周内边距 16px。这一圈是内容区到侧栏、顶栏和视口右缘的全部距离。ProLayout 内容区默认还有上下 32px、左右 40px，要清成 0，不要和这 16px 叠在一起。第一行是面包屑，不放进顶栏，页头标题条隐藏（页名已经在面包屑里）。面包屑最小高 22px，下边距 12px，字号 14、行高 22。分隔符 `/` 左右各 8px。前面的可点，色是次要文字；最后一段是正文色，不可点。换页时面包屑不动，只有下面的正文滑入。没有面包屑时不要留出那一截空带。

视口锁住：页面本身不滚。普通页滚内容区；满高表只滚表体；系统设置只滚表单，保存条贴底。

### 动效与状态

| 项 | 值 |
| --- | --- |
| 前进 | 280ms，`cubic-bezier(0.22, 0.8, 0.24, 1)`，从右侧 8%、透明度 0.28 滑入 |
| 后退 | 同一时长和缓动，从左侧 6% 滑入 |
| 同级切换 | 仍按侧栏上下顺序滑。淡入只留给刚进壳的第一页：200ms，起点透明度 0.2，无位移 |
| 减少动效 | 不滑 |

必须改密时，除了个人设置，任何地址都把人送去改密，不先画出目标页。

「主题与布局」不在顶栏。入口在个人设置里，打开右侧设置抽屉，右下角那个悬浮手柄隐藏。抽屉管布局，不管这颗图标的下拉。抽屉里如果改了深浅，要和顶栏下拉是同一份选择。抽屉里改完，布局仍是「混合」、侧栏不拆、顶栏仍固定。

### 不搬

- 不要把面包屑放回顶栏，也不要在内容区再画一条页标题。
- 不要在窄屏保留这只侧栏。窄屏用「手机壳」。
- 不要把深浅色放进用户菜单，也不要在顶栏放一颗只切两态的开关。桌面就是这颗图标加三项下拉。

## 设置页

来源：范本 `docs/UI_SPEC_EXTRACTION.md` §8。`docs/DESIGN.md` §3.7 只记行为，尺寸以本节为准。两种骨架。系统设置是「页签卡片 + 表单卡片」。个人设置是「左导航 + 右表单」。字段随产品换，骨架留下。

### 系统设置

路由 `#/system/settings`。内容区不滚，底边距改为 0。页签和表单是两张白卡片，中间间距 16px。

页签条高 48px，圆角 12，左右内边距 8px，边和阴影与数据统计卡片相同。每个页签高 46px、字号 14、字重 600，页签之间左间距 4px，下划线高 2px。这一页的页签是：品牌标识、登录安全、登录验证码、列表刷新、界面动效、执行端发布。执行记录和日志的页签条用同一套圆角、边和阴影。

表单占满剩下的高度。字段区自己滚，内边距 `16px 24px 8px`。底部操作条不滚：内边距 `12px 24px`，按钮间距 8px，上边框，阴影 `0 -6px 16px rgb(0 0 0 / 6%)`。

列表页上的页签（执行记录、高级任务）只用同一条页签条，不要把保存条也搬过去。

### 个人设置

路由 `#/account/settings`。整页可滚。卡片最小高 560px，圆角 8px。浅色底白，深色底 `#1f1f1f`。

左导航宽 224px，内边距 `12px 0 12px 16px`，右边一条分割线。按钮满宽，下边距 4px，内边距 `8px 16px`，圆角 8，无边框，文字左对齐。选中底是主色浅底、字是主色。深色选中底是主色 20% 混透明。五项：基本设置、安全设置、账号绑定、新消息通知、主题与布局设置。最后一项打开控制台壳的布局抽屉。

右栏内边距 `8px 40px 32px`。标题 20px、字重 600、行高 28px，上下边距 `16px 0 24px`。基本设置里表单最宽 448px，右侧头像列宽 144px，两列间距 48px。

到期或首次必须改密时，卡片上方先出警告条：「密码已到期，请先修改密码」或「首次登录或管理员重置后，请先修改密码」。此时壳会把别的地址送回这一页。

### 不搬

- 直出时「执行端发布」这个页签仍在。不要把范本的发布命令抄进说明。
- 列表页上的页签不要带保存条。

### 验收

- [ ] 系统设置的页签和表单是两张卡片，间距 16px。滚的是字段，保存条贴在表单底
- [ ] 页签条高 48px，页签字重 600
- [ ] 个人设置左栏 224px。选中项是主色浅底
- [ ] 「主题与布局设置」打开壳的设置抽屉，不在这一页里再做一套主题表单

## 详情

来源：范本 `docs/UI_SPEC_EXTRACTION.md` §9。`docs/DESIGN.md` §3.8 只记行为，尺寸以本节为准。详情有两种，不要合成一张又像抽屉又像整页的版式。

### 从列表打开的右侧抽屉

桌面从右缘推出，盖住内容，底下的表还在。手机关掉抽屉，改成手机壳的底部弹层，并且把写死的抽屉宽度铺满屏幕。

| 用途 | 宽 |
| --- | --- |
| 执行详情 | 760px。标题 `执行详情 · 派单 #{id}` |
| 运行日志 | 960px |
| 指标口径 | 大号抽屉 |

执行详情是这一类的填好例子，正文可以复用：

1. 可选的进度折叠条，圆角 8。
2. 页签。执行详情的第一项是「应用日志」。
3. 头：左标题 16px，下一次要说明 12px（`派单 #id · 第 n 轮`），右结果标签。
4. 三列信息格。一格一个标签加一行值，标签 12px 三级文字色，值超出省略。整组边框、圆角 6，格与格之间一条左边线，格内边距 `8px 12px`。
5. 再往下的分区用上边框分开，标题字重 600。

关掉抽屉即销毁内容。再打开是当前这一行，不留上一次的滚动位置。

### 运行日志抽屉

放在「详情」里：它是从列表打开的右侧抽屉的一种，宽 960px，和执行详情共用「筛选组件」和同一个日志框。正文从上到下，块间距 16px：

1. 一行当前状态：蓝色小标签「正在」加一句话，14px。
2. 可选的一行原始日志，13px 次要色，最多两行，悬停看全文。
3. 筛选面板，直接用「筛选组件」，不另做一套展开收缩：圆角 12 的卡，内边距 `13px 18px`；字段标签在控件上方，控件 34px，列间距 24px、行间距 16px。字段顺序「运行日志」（派单下拉）、「筛选」（搜索框，占位「关键字（公司名 / 税号 / 步骤）」）、「只看告警 / 失败」（默认尺寸开关，垂直居中在 34px 里）；收起时露出前两个，第三个收进「展开」。按钮区靠右、与控件底对齐：「展开 / 收起」文字链加「复制」「下载全文」，都是 34px。面板的按钮插槽换掉默认的「重置 / 查询」，因为这里没有查询语义。三列或四列布局下末列按内容宽，字段均分剩余宽度，避免三个按钮被挤出格子。不要用 small 尺寸控件。
4. 面板下方 12px 一行状态：标签「实时」（蓝）或「已结束 · 状态」，后面是「共 N 行，这里显示最近 M 行」次要色。状态行**右端**两颗 28px 的图标文字钮（仅从「数据统计」「当前任务」的「运行日志」打开的这一只带；执行详情里那份已有「完整日志」链接，不重复）：一是「弹窗最大化查看」（展开图标），点开宽 `min(1200px, 100vw - 48px)`、高 `100vh - 48px` 的弹窗，里面是同一份日志（不带派单下拉，也没有这两颗钮）；二是「撑满剩余高度」（列高图标），点一次日志框的高度从默认 460px 变成「抽屉正文底部 - 24px」，再点收回；展开筛选面板、改窗口大小时跟着重算，高度变化 280ms 缓动，撑满时图标变主色。
5. 日志框：恒为深色底，12px 等宽，行高 18px，圆角 6，内边距 `8px 10px`。

执行详情（760px）「应用日志」页签里的运行日志是同一个组件、同一套面板，只是没有「运行日志」下拉，只有两个字段：窄于 768px 时两列（末列按内容宽），收起露出「筛选」，「只看告警 / 失败」收进「展开」。

### 整页详情

流程、Skill、录制走这一类。地址是列表路径再加一段 id。页名在壳的面包屑里，内容区不再放页头。

正文从上到下，块间距 16px：一行标识（等宽小字或标签）、一句次要说明、然后卡片或页签。页面跟内容一起滚，不要锁成满高表。只读的发布版要在说明里写清「改须新版本」，不要在页上放一个看起来能保存的主按钮。

### 不搬

- 不要把执行日志的字段名做成所有详情的默认格。格的排法留下，格子里的词随业务换。
- 整页详情不要再套一层 760px 宽的抽屉。

### 验收

## 手机壳

来源：范本 `docs/UI_SPEC_EXTRACTION.md` §10。`docs/DESIGN.md` §3.9 只记行为，尺寸以本节为准。视口宽度小于 768px（媒体查询用 `767.98px`）时用这只壳，组件用 antd-mobile。颜色仍走 `--ant-*`，不另做一套手机色。

### 解剖

整屏高 `100dvh`，自身不滚。顶栏吸顶，高 52px，内边距 `0 12px 0 16px`，再加上顶部安全区。底边一条分割线。

列表页左侧是标识：有 Logo 则高 26px、最宽 120px，否则是控制台壳的默认 Logo（高 26px）。详情页（地址比菜单路径更深，或面包屑多于一段）改成返回钮：视觉 34×34、圆角 6、底 `colorFillTertiary`，点选热区扩到 44px。标题是面包屑最后一段，17px、字重 700，超出省略。

右侧：执行机状态、通知、账号按钮。执行机状态仍是「机器人头像」，手机上圆 22px、最多 3 颗、左右内边距 4px。账号按钮最小高 44px。头像 28px 圆、底 `#1f2329`。菜单图标 19px。有站点标签时，顶栏下面另起一条居中的错误色胶囊（圆角 4、字号 12、字重 600），不要用桌面顶栏那颗会变色的标签。

内容区自己滚，内边距 12px，底部再加 16px 和安全区。桌面 PageContainer 那 40px 左右留白在这里归零。普通卡片左右内边距 16px。换页时内容从右侧 18% 滑入，260ms，缓动 `cubic-bezier(0.22, 0.8, 0.24, 1)`，起点透明度 0.35。返回从左侧 14% 滑入。减少动效时不滑。进入新页滚回顶部。

菜单从右侧弹出，宽 `min(80vw, 300px)`。头：显示名 17px 字重 600，角色 13px 次要色。菜单组可展开，箭头 0.2s 转到 180°。子项左缩进 44px。当前项底是主色浅底。下面是主题，三列选择：浅色、深色、跟随系统。再下面：个人设置、修改密码、退出登录。点一项就关上菜单。

详情和日志用底部弹层，不用右侧抽屉。圆角 `16px 16px 0 0`。默认高 `min(92dvh, 900px)`；短表单用内容高度，但不超过这个上限。顶条最小高 52px，标题 16px 字重 600，右侧关闭。顶条不动，正文自己滚。

### 列表怎么落

执行记录、队列、高级任务在手机上是一卡一行，详情走底部弹层。没有单独手机页的路由仍用桌面组件，只是套进这只壳、左右留白归零。不要为了壳去给每一页补一套卡片。
