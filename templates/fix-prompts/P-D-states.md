# P-D · 交互状态补齐

```text
仓库：[项目名]。只改前端，不动接口。

背景：缺 loading/empty/error；提交无防重；危险操作无确认。

基准：Empty / Spin|Skeleton / Modal.confirm|Popconfirm。

要做：
1. 异步页三态完整。
2. 提交中 loading 且不可再点。
3. 危险操作统一确认并说明后果。
4. 重复逻辑抽公共组件。

不要做：不改数据流；不重写整文件；不碰范围外；不新增 UI 依赖。

自查清单：
[ ] 错误可重试
[ ] 空数据与筛选为空文案区分
[ ] 连点只发一次请求
[ ] 取消确认不发请求
[ ] 构建与 lint 通过
```
