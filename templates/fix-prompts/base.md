# 修复 Prompt 通用底线

每个修复分组 Prompt 必须包含下列「不要做」前四条（迁栈组可按例外新增 React 19 + Ant Design 6）：

```text
不要做：
- 不改接口调用、数据流和状态逻辑（hooks / store / watch / effect 保持原样）。
- 不重写整个文件，只替换必要的 JSX / template / 样式片段。
- 不顺手调整范围外页面的样式、布局和文案。
- 不新增第三方 UI 依赖。例外：本组目标就是从「无组件库」迁到组织推荐栈时，可以新增 React 19 与 Ant Design 6，不另加第二套 UI 库。
- 设计稿是 Arco 时，不按它的组件硬套，不新增 `.ant-*` 覆盖去贴像素，不重写 `.ant-btn`。按钮继续用 antd `Button`，`loading`、`disabled`、`danger`、`type`、`htmlType` 必须仍然有效。外观只改 token。不改组件原有的焦点、键盘、展开、校验和确认。
```

完整骨架：

```text
仓库：[项目名]（[框架 + UI 库 + 样式方案]）。只改前端 [目录]，不动后端和接口。

背景：…
基准：…
范围：…
问题：…
要做：…
不要做：…（含上方底线）
自查清单：…
```
